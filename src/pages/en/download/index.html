Before you install

TIMEperative is not yet in the Microsoft Store or on Google Play, and the Windows installer is not code-signed yet. Your browser and your device therefore check the file before they install it. This is what you will see, and what to choose.

Windows

  1. Microsoft Edge may say that the file isn’t commonly downloaded. The download then shows 100%, but Edge keeps the file back until you decide. Open Downloads with Ctrl+J, choose More actions (…) next to the file, then Keep, Show more and Keep anyway.
  2. Open the file. Windows may show “Windows protected your PC”: choose More info, then Run anyway.
  3. The installer sets TIMEperative up for your Windows user, without administrator rights.

Windows asks again for each new version you download from this page, as it does not know that version yet. Where Smart App Control is on, or where your organisation blocks unsigned apps, Windows offers no Run anyway; ask your IT team, or wait for the signed release.

Android

  1. Chrome may say “File might be harmful”. Choose Download anyway.
  2. Open the downloaded file. The first time, Android says that your phone isn’t allowed to install unknown apps from this source. Choose Settings, switch on Allow from this source, and go back. On Android 7, switch on Unknown sources in Settings, under Security, instead.
  3. Play Protect may recommend scanning the app, because it has not seen TIMEperative before. Choose Scan app.
  4. Android asks whether you want to install this app. Choose Install.

If the download reaches 100% but the file is not in your downloads, start it again from this page. Once TIMEperative is installed, you can switch Allow from this source off again in the phone’s settings.

Early access

TIMEperative is an alpha release. It keeps your data in a database on your device, and each update migrates it and keeps snapshots of the last versions. Still, export your entries now and then while the app is in alpha.
