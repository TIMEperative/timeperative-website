Converters

A converter turns the entries you choose into the import file your ERP or HR system expects: its columns, its date and number formats, its lists and the values it needs. We are building the first converters now.

What a converter will do

  • Write the file your system's own import accepts, with the column names, formats and list values of your installation and its language.
  • Check every entry before it writes the file, and tell you which ones need your attention.
  • Add an ID to every entry, in a field you choose, so that TIMEperative can match the records your system creates when you read its export back.
  • Run in the app on your device. Your entries reach your system only when you import the file there yourself.

Converters are not in the app yet. We start with Microsoft Dynamics 365 Project Operations, then Oracle NetSuite and Microsoft Dynamics 365 Finance and Supply Chain Management. The news will say when each one is ready.
