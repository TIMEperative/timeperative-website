Avant l'installation

TIMEperative n'est pas encore disponible sur le Microsoft Store ni sur Google Play, et le programme d'installation Windows n'est pas encore signé numériquement. Votre navigateur et votre appareil vérifient donc le fichier avant de l'installer. Voici ce qui s'affichera, et ce qu'il faut choisir.

Windows

  1. Microsoft Edge peut indiquer que le fichier n'est pas couramment téléchargé. Le téléchargement affiche alors 100 %, mais Edge retient le fichier jusqu'à ce que vous décidiez. Ouvrez les téléchargements avec Ctrl+J, sélectionnez « Autres actions » (…) à côté du fichier, puis « Garder », « Afficher plus » et « Garder quand même ».
  2. Ouvrez le fichier. Windows peut afficher « Windows a protégé votre PC » : sélectionnez « Plus d'informations », puis « Exécuter quand même ».
  3. Le programme d'installation configure TIMEperative pour votre compte utilisateur Windows, sans droits d'administrateur.

Windows pose à nouveau la question pour chaque nouvelle version que vous téléchargez depuis cette page, car il ne connaît pas encore cette version. Lorsque le Contrôle intelligent des applications est activé ou que votre organisation bloque les applications non signées, Windows ne propose pas « Exécuter quand même » ; contactez votre service informatique ou attendez la version signée.

Android

  1. Chrome peut afficher « Fichier potentiellement dangereux ». Sélectionnez « Télécharger quand même ».
  2. Ouvrez le fichier téléchargé. La première fois, Android indique que l'installation d'applis inconnues provenant de cette source n'est pas autorisée sur ce téléphone. Sélectionnez « Paramètres », activez « Autoriser depuis cette source », puis revenez en arrière. Sous Android 7, activez plutôt « Sources inconnues » dans les paramètres, sous « Sécurité ».
  3. Play Protect peut recommander d'analyser l'application, car il ne connaît pas encore TIMEperative. Lancez l'analyse.
  4. Android vous demande si vous voulez installer cette appli. Sélectionnez « Installer ».

Si le téléchargement atteint 100 % mais que le fichier ne figure pas dans vos téléchargements, relancez-le depuis cette page. Une fois TIMEperative installé, vous pouvez désactiver à nouveau « Autoriser depuis cette source » dans les paramètres du téléphone.

Accès anticipé

TIMEperative est une version alpha. L'application stocke vos données dans une base de données sur votre appareil ; à chaque mise à jour, celles-ci sont migrées et des instantanés des dernières versions sont conservés. Exportez tout de même vos entrées de temps à autre tant que l'application est en version alpha.
