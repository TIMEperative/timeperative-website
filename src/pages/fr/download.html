Avant l'installation

Windows ne le demande qu'une seule fois

Le programme d'installation n'est pas encore signé numériquement. Windows peut donc afficher le message « Windows a protégé votre PC » la première fois. Si vous avez téléchargé le fichier depuis cette page, sélectionnez « Plus d'informations », puis « Exécuter quand même ». Lorsque le Contrôle intelligent des applications est activé ou que votre organisation bloque les applications non signées, Windows ne propose pas ce choix ; contactez votre service informatique ou attendez la version signée.

Android ne le demande qu'une seule fois

La première fois que vous ouvrez le fichier APK, Android vous demande si votre navigateur est autorisé à installer des applications. Autorisez-le pour cette installation ; vous pourrez désactiver cette option par la suite dans les paramètres de votre téléphone. TIMEperative sera disponible ultérieurement sur Google Play et dans le Microsoft Store.

Accès anticipé

TIMEperative est une version alpha. L'application stocke vos données dans une base de données sur votre appareil ; à chaque mise à jour, celles-ci sont migrées et des instantanés des dernières versions sont conservés. Exportez tout de même vos entrées de temps à autre tant que l'application est en version alpha.
